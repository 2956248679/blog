## 为什么建这个博客

作为准运维工程师，**做出来**比说出来更有说服力。

这个博客本身就是我的运维项目——从 Hugo 静态生成、DaisyUI 样式、Docker 容器化到 GitHub Actions 自动部署，每个环节都是实实在在的运维技能。

## 技术栈

| 技术 | 作用 |
|------|------|
| Hugo | Go 语言静态站点生成器 |
| Hugo Narrow | Tailwind CSS 4 + DaisyUI 主题 |
| Nginx Alpine | 容器化 Web 服务 |
| Docker Compose | 服务编排 |
| GitHub Actions | CI/CD 自动部署 |
| 阿里云 ECS | Ubuntu 24.04 云服务器 |
